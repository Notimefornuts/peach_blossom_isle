# Shoreline material trial

`shore-rock-color.webp` and `shore-rock-normal.webp` are derived from
[Rock 01 by Rob Tuytel on Poly Haven](https://polyhaven.com/a/rock_01),
available under [CC0](https://polyhaven.com/license).

The color map has been desaturated and softened to preserve the miniature's
existing green-gray palette. Both images are 512 × 512 WebP files. Only a
short section of the front shoreline uses these maps for comparison. The
software and low-device path uses the color map without the normal map.
